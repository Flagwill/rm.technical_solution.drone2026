\section{电路参数}
%电路功耗、所有电容总量、工作时电压范围等
整车有两个电容组，超级电容组和浪涌吸收电容组。其容量参数及工作电压如下所示：
\begin{itemize}
    \item 超级电容容量：加入保护电路后参数为$\qty{2.7}{\V}$/$\qty{15}{\F}$，标称容量为$\qty{1896.075}{\J}$。工作电压范围为$\qty{7}{\V}\sim\qty{15.5}{\V}$。
    \item 浪涌吸收电容容量：参数为$\qty{50}{\V}$\ /\ $\qty{20}{\mF}$，标称容量为$\qty{25}{\J}$。工作电压范围为$\qty{24}{\V}\sim\qty{50}{\V}$。
\end{itemize}

车载模块及其用途、设计最大功率：
\begin{itemize}
    \item 超级电容充电：用于给超级电容充电，设计最大功率为$\qty{120}{\W}$。
    \item 超级电容升压：用于将超级电容升压至$\qty{26}{\V}$输出，设计最大功率为$\qty{240}{\W}$。
    \item NUC供电电源：用于给NUC供电，设计最大功率为$\qty{200}{\W}$。
    \item IMU: 用于精确获取机器人姿态，提高运动的准确性。
    \item 荧光充能装置:用于给荧光弹丸进行充能，设计功率为$\qty{1.632}{\W}$。
\end{itemize}
