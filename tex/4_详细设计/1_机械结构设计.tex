\subsection{飞行平台}

飞行是一台无人机最基础的功能，飞行平台的结构是无人机最重要的结构。对它的要求是：
\begin{enumerate}
    \item 整体刚度大，能够减少无人机在飞行过程中的震动，并且在发生意外坠机时能保证不发生严重破坏。
    \item 质量轻，轻量化设计理念贯穿整个无人机机械设计过程，飞行平台是减重的大头。
\end{enumerate}

无人机在飞行时会产生很多高频震动，如果机身设计不稳定或刚度不够会极大程度影响飞行平稳性和飞机的操控性，进而影响发射系统，所以优秀的飞行平台设计是赛场上空中机器人发挥优秀的基础。接下来依次介绍飞行平台各个部分的设计以及之间的联系。

\subsubsection{机身整体}

机身整体是飞行平台的骨架，承载所有其他结构。机身整体包含机身中心、折叠机臂、快拆脚架和弹仓四个部分。

\paragraph{机身中心}

机身的中心结构是整个飞行平台的中心，采用上下两层厚碳板夹住铝柱和机臂构成，中心碳板空白处做大量镂空减重。四根机臂从中心向四周伸出，下接脚架，上接弹仓，雷达和激光检测模块固定在弹仓中心的浮台上，飞控和主控则利用弹仓外冗余空间直接用纳米胶分别固定在上下层碳板上。

\paragraph{机臂设计}

机臂是连接机身中心与旋翼电机的关键结构，需要承受飞行时的拉力与震动。今年的机臂在去年碳方管方案基础上新增了折叠功能，以满足检录收纳尺寸要求。

机臂选用$30\times30$、壁厚$1\mathrm{mm}$的碳方管。方管形变比圆管小，不需要调节桨平，同时不需要在中心板间设置管架并可以在管身上镂空，可以在保证强度得同时较圆管减少大量重量。方管机臂侧面的镂空采用拓扑方法，通过Solidworks的拓扑仿真插件仿真后得出具体镂空形状，在保证强度的前提下实现最大程度的减重。

对于折叠机构，在赛季初，本着能用的基础上尽量减重的原则设计了初版的折叠件。但很快在区域赛就暴露出了拆装复杂、运输过程中非常容易发生断裂的问题，于是基于不大幅增重、加强强度、简化折叠流程、减少加工复杂度的需求设计了新的折叠件
最后的方案是用塞打做转轴（成品转轴要么强度不够要么太重），两侧用手拧螺丝拧入实现折叠（本来考虑搭扣的方案，但搭扣还是要么太重要么强度不够），同时在碳方管外侧平面上拧上螺丝前垫上钢片以降低螺丝对碳板的压强，在不增大折叠件体积的前提下提高整体的强度。最后在整个国赛期间没有损坏，实现折叠稳固，外端机臂与内端机臂相对运动幅度较小，折叠时间从初版的单人5min压缩至单人1min30s， 同时单折叠件重量仅50g，为圆管成品件的1/3，基本满足设计需求。

\subsubsection{弹仓浮台}

弹仓浮台位于四个分体式桨保的正中间位置，处于机身顶部中心区，通过从弹仓底预留的孔洞四根伸出长铝柱支于弹仓上。浮台上集中安装了三种关键传感器，其布局需同时满足各自的安装规范与相互之间的距离约束。

平台上安装：
\begin{itemize}
    \item \textbf{Livox MID-360雷达}：采用纳米胶与电工胶将雷达直接粘贴在海绵垫上，这种减震方式效果最佳，既保证了雷达的稳定性，又不会在飞行中产生过大的机械位移。雷达直接安装在弹仓浮台上。
    \item \textbf{激光检测模块}：安装在长保护杆上，长保护杆安装在弹仓浮台上。用于检测反无人机激光并触发规避机动。
    \item \textbf{UWB定位模块}：通过两根碳板夹紧保护杆中部的结构安装于弹仓浮台上，使其满足裁判系统安装要求。
\end{itemize}

浮台的设计需要考虑传感器的安装位置、减震效果以及与周边结构的避让关系，尤其是安装螺丝的干涉问题。虽然激光检测模块的保护杆可能会对雷达产生轻微遮挡，但实际测试表明影响不大，不影响定位性能。此外，UWB定位模块与激光检测模块之间存在安装距离要求，布局时已确保两者满足最小间距约束。

\paragraph{UWB定位模块安装}

UWB定位模块的安装是浮台设计中的重点与难点。该模块通过两根碳板夹紧保护杆中部实现固定，碳板之间填充大量铝柱以提高整体机械强度，确保在任意位置施加与其垂直方向$40\mathrm{N}$的力时，定位模块底部所在平面相对于水平面的偏移不超过$10^{\circ}$。

在材料选择上，定位模块安装区域内严格禁止使用可被磁化的钢制螺丝，全部采用铝制螺丝拧紧；支架小范围内同样不得出现钢制螺丝与钢制螺母，以避免对UWB信号产生干扰。同时，整个定位模块的机械安装不允许存在任何间隙，用于夹持两根碳板的管夹必须拧紧至规定力矩，确保结构刚性。


保护杆碳管相对于弹仓平台不允许发生转动。为实现这一约束，未采用在碳管上直接打单一大孔穿螺丝的方案，而是在两个正交方向上各穿一根螺丝，通过双向约束彻底限制保护杆的转动自由度。

\subsubsection{动力系统}

动力系统是无人机飞行的核心，直接决定飞行性能与续航能力。动力系统主要由旋翼电机与桨叶两部分组成。

\paragraph{旋翼电机}

本赛季采用HM8110 110kv UL旋翼电机，性能稳定可靠。满载整机重量将近$16\mathrm{Kg}$，电机始终温度正常，从未出现过热等异常情况。

\paragraph{桨叶}

配套使用Tmotor CFPROP Generation3桨叶，直径28英寸，螺距9.2英寸。大桨叶带来以下优势：
\begin{itemize}
    \item 提升气动效率，增加续航时间
    \item 更大的桨叶能产生更大的总体升力，改善飞行稳定性和悬停性能
    \item 大桨叶具有更大的转动惯量，像陀螺仪一样有助于稳定无人机姿态
    \item 大桨叶在低转速下工作，产生的气流更平缓，湍流更少，悬停和低速飞行时更加平稳
\end{itemize}

但大桨叶也带来缺点：让整架无人机更难控制，任何微小的不平衡都会被放大，导致整机产生更剧烈的振动，严重影响飞控传感器的精度，所以对机身结构的稳定性要求更高。

\subsubsection{桨保}

桨保是覆盖在旋翼外围的保护结构，起到保护桨叶、防止异物进入以及安全防护的作用。今年采用分体式桨保设计，主要原因是配合机臂折叠需求，满足检录收纳尺寸限制。

桨保分为框架与覆盖网两部分。

\paragraph{桨保框架}

分体式桨保框架相比去年的一体式桨保，最大的优势是便于维护。去年一体式桨保虽然刚度高、重量轻（约$1.2\mathrm{Kg}$），但飞机内部的中心板和飞控都被桨保覆盖，每次拔插飞控线或检修内部结构都需要拆卸桨保，维护非常不便。

分体式桨保的缺点是重量略增（四个分体式桨保加起来约$1.6\mathrm{Kg}$），强度较低，侧面撞击地面时桨叶容易碎裂。但每个桨保独立安装，维护时只需拆卸对应侧的桨保，且桨叶电机容易连接到中心板上的pcb板上，大大提升了维护效率。

\paragraph{桨保覆盖网}

覆盖网选用2.5*2.5(cm)6股尼龙渔网，在满足规则手册检录要求的前提下进一步减重。由于网孔较大，桨保覆盖网并不能够防止小弹丸进入桨叶，但28寸的大桨叶受到小弹丸击打一般只会出现裂痕，不会有较大影响，对飞行影响几乎可以忽略不计。


\subsection{发射系统}

飞行平台是空中机器人的基础，发射作为无人机最主要的功能，发射系统决定了无人机的上限。优秀的无人机一定有优秀的发射系统。

机械上，对发射系统的要求为云台活动范围大，任意角度高频发射不卡弹，发射精度高散度低。

\subsubsection{云台}

云台是连接发射系统与机身的关键结构，承载发射机构、相机、图传等核心组件。云台的活动范围直接决定打击视野，转动惯量则影响云台响应速度。

今年云台进行了大幅改动，主要体现在元件布局的重新设计上。去年云台采用竖向双相机分布，今年改为横向双相机分布，并将两个相机架高，下面留出一层走线空间。这种布局改动带来以下优势：
\begin{itemize}
    \item 降低了整个云台Pitch轴的转动惯量，大幅改善云台响应速度
    \item 结构更加紧凑，空间利用率更高
    \item 走线更加优雅整洁
    \item 相机安装模块实现减重
\end{itemize}

图传模块安装在双相机的下面一层，这样既没有让云台架（长脖子）变得更长，又可以让图传放在枪管的正下方，方便云台手瞄准，同时可以看到弹丸落点，便于修正弹道。

此外，小电脑从云台上移到了弹仓后面，这一改动进一步减小了云台的转动惯量，显著改善了云台的响应性能。

云台的位置前置，不在传统的飞机中心点上，目的是为了获得更大Yaw轴视野，而且为了在左右旋转时不与脚架发生干涉特意缩短了云台板的长度，最终实现云台水平$180^{\circ}$旋转，非常有实战意义。

云台采用双相机模块，使用$12\mathrm{mm}$与$5\mathrm{mm}$焦距的相机来应付远近不同的目标。激活能量机关时启用$5\mathrm{mm}$焦距镜头，攻击地面单位与敌方基地时使用$12\mathrm{mm}$焦距镜头锁定目标。根据各自的视野需求，12mm相机竖放、安装孔朝上，5mm相机横放、安装孔水平朝外，分别布置在云台中心碳板的右侧与左侧，使12mm相机位于螺丝刀不会与Pitch轴电机干涉的位置。

双相机安装件左右两边设有C板和IMU的安装孔位，便于接线与维护。整个模块采用带定位的快拆设计，将加工件分为三部分，并制作了专用的相机定位件：安装时定位件同时与起始件和相机安装件的两个面配合，安装完成后取下即可。该方案在视觉标定时方便拆卸，且不会因拆卸维修导致需要重新标定。此外，螺丝孔位置经过合理规划，使每个分部件和每个相机都能单独拆卸，整个相机模块也能整体拆下。

\paragraph{弹丸链路}

云台链路采用队内成熟的鹅颈链路，同时在链路上涂抹了干性润滑油，有效减小了弹链阻力，提升了供弹流畅性。

Pitch轴采用四边形连杆传动，实现电机偏置，为连杆、起始件等结构的设计留出了较大的空间。

\paragraph{发射机构}

17mm小弹丸是依靠一对摩擦轮的旋转发射出去，而单发限位是发射机构中非常重要的结构。今年继续采用轴承式单发限位方案，通过在起始件上加一对U型轴承来限制预制位弹丸的活动。轴承是固定的，不会像拉簧一样反复拉动，多发下弹速较拉簧更稳定，而且轴承能够使每个出去的弹丸都在固定位置起到定心效果，提升发射精度。

今年发射机构的核心改动是将摩擦轮电机从M3508更换为M2006。M2006电机体积更小、重量更轻，且扭矩特性更适合摩擦轮发射场景。同时将摩擦轮改为曲面摩擦轮以提升弹丸的定心度，实际使用时摩擦轮中心间距55mm。经过实际测试，更换曲面摩擦轮后的发射散度得到了显著改善。

轴承间距是影响发射性能的关键参数。今年对轴承间距进行了额外的测试优化，通过制作demo反复测试，确定了最优间距为，既保证单发限位效果，又确保拨盘能顺畅转动。轴承的安装位置在摩擦轮之后，注意不与摩擦轮发射干涉。

\subsubsection{拨盘}

拨盘沿用队内成熟的上供弹技术，采用2006电机驱动，通过调整挡边的长度、研磨挡边与弹丸相切角，降低了弹丸在拨盘中受到的阻力，最终能实现一千发卡弹次数小于等于1。拨盘位于云台架上方，通过波纹管与弹仓连接，波纹管起到了扩展容弹空间的作用，同时将飞机中心下沉，有利于飞行稳定。

\subsubsection{云台架}

云台架是连接机身与云台的部分，整个云台通过它吊装固定在机身下中心板上。由于云台需要向上仰角以实现近距离击打能量机关，为了防止弹丸发射弹道与桨保干涉，云台架设计得较长，我们称之为"长脖子"。

云台架采用三块厚碳板形成方形结构来吊装云台，能抵抗扭转与横向位移，大大增加了云台的稳定性，有效减小因为云台运动产生的晃动与形变。拨盘下沉到云台上方，用单独一层碳板固定拨盘与直角链路，再用波纹管连接拨盘与弹仓，消除了长段竖直链路带来的阻力问题。

今年的小电脑上移至波纹管后方，用小电脑壳直接安装在拨盘下方的碳板上。下方吊装用于飞手和云台手灯语交流的箭头灯带。
