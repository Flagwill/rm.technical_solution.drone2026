\section{综述}

本赛季哨兵机器人取消了轨道的限制，并且提高了哨兵机器人各项性能属性，这是官方有意推动各高校对于自动步兵机器人的研发。血量和底盘功率的提高加上高额的750发载弹量、枪口热量上限和冷却速度，使哨兵机器人的定位从之前的防守型机器人转变为可攻可守的移动炮塔。并且哨兵机器人本赛季的难点是如何使其可以稳定地在场上运行，所以需要提供更多的时间给控制组与视觉组进行调试。全自动的算法意味着稳定性的要求极高，应尽早模拟、尽量真实的环境去调试、优化哨兵机器人。所以本赛季哨兵机械并不会重新设计，而是在原有的步兵机器人的基础上修改其弹仓、加上换测速机构与装上各种传感器，使其尽快能用于控制与视觉的调试。根据哨兵机器人各项规则要求，我们给哨兵机器人制定了哨兵技术方案目标表，如\tabref {tab:哨兵技术方案目标}所示：

\section{目标实现计划}
\begin{itemize}
    \item 在原有步兵的基础上修改哨兵弹仓，达到至少能够搭载750发小弹丸的要求。
    \item 搭载双测速，设计换测速机构并根据当前枪管热量实现自动切换，提高射击持续时间。
    \item 完成哨兵状态机，使哨兵能在手动模式（用于调试）与自动模式间切换，并根据场上情况自主决策是否进入防御或进攻模式。
    \item 通过传感器实现对场上环境的实时感知与构图，借此实现定位位姿、自主路径规划与自主上坡。
    \item 通过对场地上标签的识别，实现对自身位姿信息的修复。
\end{itemize}
